# DNK Web

Веб-система для управления нефтебазами с React-интерфейсом, Node.js API, PostgreSQL и MinIO.

## Запуск через Docker Compose

1. Скопируйте `.env.example` в `.env` и задайте уникальные пароли.
2. Запустите `docker compose up --build` из каталога `DNK_web`.
3. Откройте `http://localhost:5000`.

Не используйте демонстрационные значения для публичного или производственного развертывания.
