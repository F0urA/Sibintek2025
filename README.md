# Sibintek 2025

Набор учебных и демонстрационных проектов, подготовленных в рамках Sibintek 2025.

## Проекты

- **DNK_blackLine** — веб-приложение для управления автопарком, финансами и розничными операциями. Frontend: React + TypeScript; backend: Go; база данных: PostgreSQL. Запуск через Docker Compose описан в `DNK_blackLine/README.md`.
- **DNK_web** — веб-система для управления нефтебазами. Frontend: React; backend: Node.js/Express; PostgreSQL и MinIO. Инструкции: `DNK_web/README.md`.
- **DNK_news** — новостной сервис на Flask. Инструкции: `DNK_news/README.md`.
- **SMP** — приложение на Rust/Rocket. Инструкции: `SMP/README.md`.

## Требования

Для контейнерных проектов нужны Docker и Docker Compose. Для локальной разработки также понадобятся соответствующие версии Go, Node.js, Python или Rust.

## Безопасность

Не добавляйте в Git реальные `.env`-файлы, приватные ключи, журналы или данные пользователей. Для локальной настройки скопируйте `.env.example` в `.env` и задайте собственные значения. Перед публикацией убедитесь, что в конфигурациях нет рабочих паролей, токенов, адресов внутренних систем и персональных данных.
