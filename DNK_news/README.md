# DNK News

Новостной веб-сервис на Flask.

## Запуск

Проект и Docker-конфигурация находятся в `src/`. Перед запуском Docker Compose скопируйте `src/.env.example` в `src/.env` и задайте случайный `SECRET_KEY`. Запустите `docker compose up --build` из `src/`.

Храните секреты и локальные настройки в `.env`; не публикуйте рабочие ключи, базы данных и пользовательские данные.
